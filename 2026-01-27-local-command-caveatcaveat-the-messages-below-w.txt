  🔴 Problemas Críticos Encontrados

  1. Justfile incompatible con Windows (CRÍTICO)

  - Usa bash hardcodeado, bloqueando completamente a usuarios de Windows
  - Requiere WSL o Git Bash para funcionar

  2. Falta configuración de line endings (.gitattributes)

  - Sin este archivo, Git usará CRLF en Windows y LF en Linux
  - Causará conflictos de merge y "archivos modificados" fantasma

  3. Configuración de Django incompleta

  - Falta STATIC_ROOT (necesario para producción)
  - Paths mezclados entre pathlib y os.path.join

  4. Secrets hardcodeados en settings.py

  - SECRET_KEY y DEBUG no usan variables de entorno

  Voy a resolver estos problemas en orden de prioridad:

  📋 Cambios Realizados

  1. ✅ Justfile - Cross-Platform Compatible

  Archivo: Justfile

  Cambios:
  - Configurado shell dinámico: PowerShell en Windows, Bash en Linux
  - Agregados comandos de Django faltantes: migrate, makemigrations, shell,
  test, lint, format, check
  - Simplificados comandos de AFIP para compatibilidad (usan Python directamente
   en lugar de redirección shell)
  - Eliminado el @ de comandos para mejor debugging

  Comandos disponibles ahora:
  just run              # Servidor de desarrollo
  just watch-css        # Watch CSS changes
  just build-css        # Build CSS producción
  just migrate          # Aplicar migraciones

  just lint             # Ruff linting
  just format           # Ruff formatting
  just check            # Django checks

  2. ✅ .gitattributes - Line Endings Consistentes

  Archivo: .gitattributes (nuevo)

  Beneficios:
  - Fuerza LF en todos los archivos de texto (Python, JS, HTML, CSS, etc.)
  - Previene conflictos de merge por line endings
  - Elimina "archivos modificados" fantasma entre Windows/Linux
  - Marca archivos binarios correctamente

  3. ✅ settings.py - Configuración Mejorada

  Archivo: src/core/settings.py

  Cambios:
  - Línea 18: Paths consistentes con pathlib: str(BASE_DIR / 'apps')
  - SECRET_KEY: Usa variable de entorno con fallback seguro
  - DEBUG: Usa variable de entorno (default: True)
  - ALLOWED_HOSTS: Usa variable de entorno configurable
  - STATIC_ROOT: Agregado BASE_DIR.parent / 'staticfiles' (requerido para
  producción)
  - MEDIA_ROOT y MEDIA_URL: Agregados para manejo de uploads

  4. ✅ .gitignore - Archivos SQLite WAL

  Archivo: .gitignore

  📖 Guía para el Equipo

  Para el desarrollador en Windows:

  1. Instalar Git con Git Bash (recomendado) o usar PowerShell
  2. Instalar herramientas:
  # Python 3.13+
  # uv: irm https://astral.sh/uv/install.ps1 | iex
  # pnpm: npm install -g pnpm
  # just: cargo install just
  3. Clonar y configurar:
  git clone <repo>
  cd billing-system
  cp .env.example .env
  uv sync
  pnpm install
  just migrate
  just run

  Para ti (desarrollador en Linux):

  1. Actualizar repositorio local:
  git pull
  # No hay cambios de configuración necesarios
  just run  # Todo debería seguir funcionando

  Para ambos:

  ⚠️ IMPORTANTE - Normalizar line endings existentes:

  Después de que ambos desarrolladores hagan pull de estos cambios, ejecuten:

  # 1. Commit cualquier cambio pendiente
  git add .
  git commit -m "Guardar cambios antes de normalización"

  # 2. Normalizar line endings
  git add --renormalize .
  git status  # Verás archivos con line endings corregidos

  # 3. Commit la normalización
  git commit -m "chore: normalize line endings per .gitattributes"

  Esto solo necesita hacerse una vez después de agregar .gitattributes.

  📝 Problemas Conocidos Restantes

  Ninguno crítico, pero ten en cuenta:

  1. Justfile en Windows: Requiere PowerShell 5.1+ (viene con Windows 10+)
  2. Git Bash recomendado en Windows: Para mejor compatibilidad con comandos
  Unix-like
  3. Testing AFIP con shell interactivo: just test-afip-shell puede tener
  comportamiento ligeramente diferente en PowerShell
